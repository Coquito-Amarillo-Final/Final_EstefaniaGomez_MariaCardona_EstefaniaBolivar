# API REST Coquito Amarillo S.A.S.
Practica final Estefania Bolivar Marín, Estefania Gomez Gallego y Maria Jose Cardona Velasquez.
### Descripción breve:

La API REST Coquito Amarillo S.A.S.tiene como proósito gestionar los clientes, productos y pedidos de la empresa colombiana Coquito Amarillo S.A.S.

### URL base para probar de forma local:

`http://localhost:5000`

### Instalación:

```bash
pip install -r requirements.txt
```
