# API REST Coquito Amarillo
Practica final Estefania Bolivar Marín, Estefania Gomez Gallego y Maria Jose Cardona Velasquez.
### Descripción breve:

API REST Coquito Amarillo desarrollada con FLlask para gestionar los clientes, productos y pedidos de la empresa colombiana Coquito Amarillo S.A.S.

### Tecnologías:

* Python
* Flask
* Flask-RESTful
* Postman


### Instalación:

```bash
pip install -r requirements.txt
```

### Ejecución:

```bash
python app.py
```

### Servidor local:

`http://127.0.0.1:5000/`

### Pruebas con Postman:

La API puede probarse utilizando Postman mediante la URL base:

`http://127.0.0.1:5000/`
